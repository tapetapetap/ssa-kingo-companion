# 부록: 교과 지도 데이터 (2026-11-16)

**Feature**: [spec.md](./spec.md) · 앱 데이터의 정본은 `src/data/courses/`의 TS 파일 네 개다(이 기능의 PR에 커밋). 이 표는 2026-11-16 같은 원자료에서 TS와 함께 뽑은 사람이 읽는 표다. 데이터를 고칠 때는 TS를 고치고 이 표의 같은 줄도 고친다. 데이터 검사(`check.test.ts`)는 개수·학기별 배치·검사 규칙을 보고, 이 표와 줄마다 맞춰 보지는 않는다.

옮기는 규칙(표 → TS): 줄 이름 → B의 id, CSRankings 우리말 이름 → A의 키, 이수구분 → `core-basic` 전공코어 기초필수 · `core` 전공코어 · `advanced` 전공심화 · `lab` 실험실습 · `grad` 학석공통 · `project` 프로젝트 · `internship` 현장실습 · `research` 연구학점 · `startup` 창업, 개설 여부 예/아니오 → `offered` true/false, '—' → 칸 없음(배치의 `area`, 연구실의 `url`), 학기 '1-1' → `Term` 그대로, 경험 층은 `term: null`·`field: 'experience'`.

출처: 학과 2026 로드맵 [`sw_roadmap_26_kor.pdf`](https://cse.skku.edu/_res/cse/etc/sw_roadmap_26_kor.pdf)(학과 홈페이지 [로드맵](https://cse.skku.edu/cse/dept_roadmap.do)), 학과 교육과정 표 [`dept_curriculum.do`](https://cse.skku.edu/cse/dept_curriculum.do?pager.offset=0&lang=All)(30줄씩 7쪽, 학수번호·과목명·학점·개설 학과·개설 여부), 연구실 홈페이지(교수 목록 [`faculty.do`](https://cse.skku.edu/cse/faculty.do)에서 연 주소), [CSRankings](https://csrankings.org) 분야 목록(`csrankings.js`, 2026-07-19 판). 과목 설명 문장, 학생 이름·연락처는 담지 않는다.
