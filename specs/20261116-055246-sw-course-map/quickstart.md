# Quickstart: 소프트웨어학과 교과 지도 확인

**Feature**: [spec.md](./spec.md)

## 준비

```sh
npm install                      # 처음 한 번
npx playwright install chromium  # 레이아웃 검사를 처음 돌릴 때 한 번
```

## 자동 검사

```sh
npm run check          # 타입 검사 + 단위 테스트(묶음 규칙, 데이터 검사, 지도 모양, 상태·저장·내려받기, 진입점)
npm run build          # 배포 빌드
npm run audit:layout   # 모든 경로 × 크기 × 학생 상태. #/courses 는 router KNOWN_SUBS로 들어가고, 방향을 고른 단계도 본다(run.mjs STEPS)
npm run audit:copy     # 문구 검사
```

## 손으로 보는 흐름

1. `npm run dev` → `http://localhost:5173/#/courses`.
2. 예시 학생(설정 › 프로토타입 정보 › 예시 학생으로 보기)
   - 지도에 1-1~4-2 여덟 칸, 기초 줄과 묶음 이름(AI · 시스템 · 이론 · 융합) 아래 분야 줄, 맨 아래 경험 줄, 3학년 2학기 칸 머리 '지금', 들은 과목 채운 점.
   - 안내 줄 오른쪽 '최근 안 열린 과목' 스위치를 켜면 얇은 회색 테두리 점(최근 안 열린 과목)이 나타나고, 끄면 사라진다.
   - 진로 방향 '검색·추천 엔지니어' 고르기 → 길의 과목이 밝아지고 밝은 과목이 없는 분야 줄이 '이 길에 없는 분야' 한 줄로 접힘, 안내 줄에 진행 한 줄과 '지금 들을 만한 과목 k개', 지도 아래 '이 길의 과목' 묶음과 '이 길의 연구실'.
   - '목록 보기'를 누르면 스크롤 칸이 목록으로 옮겨 간다. 페이지 자체는 스크롤하지 않는다.
   - 과목 점(예: 추천시스템개론) 누르기 → 서랍, 주소 `?drawer=course:ESW4024`, 새로고침해도 열림. 서랍의 '먼저 들을 과목'·'다음 과목'을 누르면 그 과목 서랍.
   - 목록에서 지도에 있는 과목(예: 기계학습원론)을 누르면 스크롤 칸이 그 점으로 옮겨 가 점이 잠깐 강조된다. 로드맵 밖 과목(예: 자연어처리개론)을 누르면 서랍이 열리고, '들었어요'를 누르면 지도 맨 아래 '로드맵 밖' 줄에 점이 생긴다.
3. 새 학생(가입 인터뷰 마치기)
   - 페이지 머리 학년·학기가 '학년·학기 고르기'로 비어 있음 → 3학년 1학기 고르기 → '지금' 표시.
   - 서랍에서 '들었어요' → 점이 채워짐 → 새로고침해도 남음 → 설정 › 내 데이터 지우기 → 사라짐.
   - `#/courses?drawer=course:XXX0000` → '항목을 찾지 못했어요' 서랍.
4. 1280×640, 1440×900, 1920에서 두 학생 상태 × 방향 고르기 전·후 스크린샷: 넘침·잘림·겹침 없음, 스크롤 칸은 지도 카드 본문 하나.
5. 브라우저 콘솔 에러 없음.
