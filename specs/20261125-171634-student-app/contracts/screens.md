# 화면 배치: 추천안 캡처와 영역·부품

[디자인 후보](https://claude.ai/artifact/X6aGWhu4g5NdQJVTTdi3es) 추천안(2026-11-18에 정함)을 390px 너비에서 캡처했다. 예시 공지는 공개 학과 공지의 제목이고 학생 자료는 예시다. **명세와 다르면 명세가 앞선다**(아래 '다르게 하는 것'). 부품은 astryx 이름이다.

## 다르게 하는 것

| 추천안 | 이번 구현 | 까닭 |
|---|---|---|
| 선반은 세로 목록 3개와 '더 보기' | 가로로 넘기는 카드 줄과 '더 보기' | 설계 2/4(FR-012)가 더 나중 결정이다 |
| 내 목록은 두 절 | 두 탭 | 설계 2/4(US3-5) |
| 분야는 모두 펼친 칩 | 큰 분야(11개)를 누르면 세부 분야 칩이 열림 | 세부 분야가 91개다(FR-011) |
| 관심 없음은 저장한 뒤 이유 | 이유 칸에서 고르거나 '이유 없이'를 누르면 저장 | 이유와 행동을 한 번에 보낸다(FR-015) |
| 학년·학기는 이어진 칸(`SegmentedControl`) | 줄이 바뀌는 `ToggleButtonGroup` | 글자를 200%로 키우면 이어진 칸은 글자를 자른다(FR-006) |
| 분야 칩 | 설명이 있는 확인란 줄(`CheckboxList`), 고른 것은 위에 버튼 칩 | 한 줄 설명을 보이고 누르는 자리를 44px로 한다(FR-006·FR-011) |
| 공지 제보 | 없음 | 4단계 |
| 카드의 한 줄 설명('교육비 무료 …') | 없음(제목·주최만) | API에 한 줄 설명이 없다 |

## 틀

- 몸 바탕 `body`, 좌우 여백 20px, 위 안전 영역. 아래 메뉴 막대(홈 `house`·공지 `megaphone`·내 목록 `bookmark`·나 `user`, 아이콘 + 글자, 지금 메뉴는 강조색, 높이 48px + 아래 안전 영역). 900px부터 왼쪽 메뉴와 가운데 600px 본문.
- 화면 제목은 `Heading` 1단계, 절 제목은 2단계. 하위 화면(자세히, 나의 하위)은 왼쪽 위 뒤로 가기(`IconButton`).
- 컴패니언 목소리: 강조색 이름표 '컴패니언' 한 줄과 본문 한두 문장. 말풍선 없음.
- 주 버튼은 화면에 하나(강조색, 너비 전체). 보조 행동은 회색 `secondary`와 `ghost`.

## 화면마다

| 화면 | 캡처 | 위에서 아래로 |
|---|---|---|
| 로그인 | (없음) | 앱 이름과 한 줄 소개 → '개발용 로그인' 표시(`Badge`) → 이메일·비밀번호(`TextInput`) → '들어가기' 주 버튼. 잠김은 비밀번호 칸의 오류 글 |
| 동의 | (없음) | 제목 '시작하기 전에 확인해 주세요' → 서버 문구 → 아래 고정 '동의하고 시작하기'와 '로그아웃'(ghost) |
| 처음 질문 | [answers](screens/answers.png) | '처음 질문 1/2'와 진행 막대(`ProgressBar`) → 제목 → 학년·학기(`ToggleButtonGroup` 둘) → 진로 목표(`RadioList`) → 남은 것 글 → '다음' |
| 분야 고르기 | [fields](screens/fields.png) | '처음 질문 2/2'와 진행 막대 → 제목 → 찾기(`TextInput`) → 고른 것 칩 → 큰 분야 목록(`Collapsible`, 누르면 세부 분야 줄과 설명) → 아래 고정 막대: 'n개 골랐어요', 고른 이름, '다음' |
| 홈 | [home](screens/home.png), [처음 온 날](screens/home-first.png) | 날짜 → 컴패니언 이름표와 이유 → 가장 추천 카드(`Card`: 종류 `Badge`, D-n, 큰 제목, 주최, '이걸 보고 골랐어요' 펼치기, '자세히 보기' 주 버튼, 세 행동) → 선반 셋 |
| 공지 | [notices](screens/notices.png) | 제목 → 찾기와 '필터 n' 버튼(누르면 종류·분야 고르기 창) → 고른 칩과 정렬(`Selector`) → 목록 줄(제목, 주최 · 종류, 오른쪽 D-n) → 끝 글 |
| 공지 자세히 | [detail](screens/detail.png), [관심 있어요 뒤](screens/liked.png) | 뒤로 → 종류·D-n → 제목 → 주최 → 칸 목록(마감·게시·분야·출처) → 분야 근거 글 → '원문 열기' 주 버튼 → 세 행동. 관심 있어요 뒤 `Toast` '내 목록에 담았어요'와 되돌리기 |
| 관심 없음 | [dislike](screens/dislike.png) | 아래에서 올라오는 창: 제목, 네 이유와 '이유 없이'. '이미 해 봤어요' 뒤 활동 넣기 제안 |
| 내 목록 | [list](screens/list.png) | 제목 → 두 탭(`TabList`, 개수) → 목록 줄(다시 볼 날 글은 둘째 줄) → '마감이 지나도 목록에 남아요' |
| 나 | (없음) | 제목 → 줄 목록(고른 분야, 나에 대한 프롬프트, 나의 분석, 알림, 처음 질문) → 로그아웃 → 계정 지우기 |
| 나의 분석 | [analysis](screens/analysis.png) | 뒤로 → 제목과 쓴 때 → 컴패니언 한 줄 → 해 온 활동 → 관심 분야 → 컴패니언이 본 흐름(근거 `Badge`) → 뺀 줄 → 켜고 끄기(`Switch`) → '.md 파일로 내려받기' |
| 활동, 프롬프트, 알림 | (없음) | 뒤로 → 제목 → 칸 → 아래 주 버튼 하나 |

D-n 표시: '오늘 마감'과 D-3 안은 `Badge` warning(노란 바탕), 그 밖은 흐린 글자. '마감 없음'·'마감 지남'·'닫힘'은 흐린 글자.
